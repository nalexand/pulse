The Windows 1.0 release gates are tracked in V1_RELEASE_PLAN.md, with tutorials deferred to the final ready-candidate step. Full implementation scope remains in IMPLEMENTATION_PLAN.md. Partial means a functioning subset exists; it does not mean the full numbered feature is complete. Planned features have no working implementation yet. The complete roadmap is not being declared finished by this release.

Skipped remains excluded; completed session scope stays completed. Controllers remain optional. This review changes no runtime behavior or verification results.
